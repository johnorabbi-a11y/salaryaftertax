# AfterTaxTool V2 Pivot Summary

## Executive Recommendation

The pivot is strategically worth attempting, but only as a deliberate V2 repackaging rather than another incremental content pass. The current 25k-page salary inventory is technically clean but strategically compromised: it overlaps SalaryDecoded, carries repetition risk and appears unlikely to regain broad URL participation through further salary-page polishing alone.

## Recommended V2 Concept

**Free calculators for your pay, tax and everyday money.**

AfterTaxTool should become a smaller, broader calculator platform focused on distinct user problems: pay, tax, household money, borrowing/debt, saving and work-money decisions.

## Recommended Initial Canonical Count

**160-220 canonical URLs**, with about **180-200** as the preferred starting point.

## Current Evidence

- HTML files: 25,044
- Canonical sitemap URLs: 25,042
- Technical audits: metadata, broken links, sitemap, robots and crawl graph pass
- Crawl graph: 0 unreachable and 0 zero-inbound URLs
- Strategic issue: excessive salary variant footprint, not a current technical blocker

## Disposition Model

| Disposition | Count |
|---|---:|
| Keep | 115 |
| Repurpose | 45 |
| Consolidate | 50 |
| Redirect | 240 |
| Remove | 24,592 |

## Main Upside

A smaller V2 can reset AfterTaxTool's identity around genuinely different calculators instead of asking Google to reassess thousands of near-variant salary URLs. It also gives the portfolio clearer separation: SalaryDecoded owns salary depth; AfterTaxTool owns broad calculator utility.

## Main SEO Risk

The biggest risk is migration churn. If done, this needs one clean transformation and then stability. Repeated sitemap/canonical/URL experiments would likely make the domain harder, not easier, for Google to reassess.
