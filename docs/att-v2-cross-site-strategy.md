# AfterTaxTool V2 Cross-Site Strategy

## Principles

- Use contextual links only.
- Do not add sitewide cross-domain blocks.
- Do not imply regulated affiliation, lender affiliation or formal advice.
- Link only where the next step clearly helps the user.

## Sensible Journeys

- AfterTaxTool mortgage payment or affordability calculator -> CreditRoadmap mortgage readiness guide.
- AfterTaxTool job-change break-even calculator -> SalaryDecoded salary comparison tool.
- SalaryDecoded salary page -> AfterTaxTool pension or student-loan deduction calculator.
- WorthMyTime commute-value page -> AfterTaxTool commute cost calculator.
- CreditRoadmap affordability guide -> AfterTaxTool debt-to-income or loan repayment calculator.

## Avoid

Avoid a portfolio footer repeated on every page. Avoid turning calculators into doorway pages for the other brands. Each cross-link should pass a human usefulness test.
