# AfterTaxTool V2 Implementation Roadmap

## Phase 0 - Confirm and Freeze Plan

Create a URL-level disposition manifest, sample GSC history, identify any externally linked URLs and decide final V2 launch inventory.

## Phase 1 - Build V2 Architecture

Create the new homepage, category hubs, calculator framework, shared methodology/trust layer and reusable related-tool modules. Do not remove the old salary inventory yet.

## Phase 2 - Launch Strongest 30-50 Calculators

Build the highest-confidence calculators first: take-home pay, income tax, NI, student loan, bonus tax, pension contribution, salary sacrifice, mortgage payment, loan repayment, household budget, rent affordability, debt payoff, commute cost, job-change break-even, compound interest and emergency fund.

## Phase 3 - Consolidate Old Salary Inventory

Remove salary-number ladders from internal navigation and sitemap. Apply redirects only for broad equivalents and clear one-to-one cases. Do not blanket redirect to homepage.

## Phase 4 - Stable Sitemap

Publish one canonical sitemap containing only intended V2 URLs. Keep robots simple. Do not reintroduce a sitemap index unless the site later genuinely exceeds single-sitemap limits.

## Phase 5 - Observe

Observe crawl, discovery, indexed count, URL participation and query mix for 30-60 days. Do not keep changing architecture during observation.

## Phase 6 - Controlled Expansion

Add calculator families in cohorts only when GSC shows crawl and query appetite. No mass programmatic number variants.
