# AfterTaxTool V2 URL Disposition Summary

## Recommended Strategic Disposition

This is a first-pass planning model, not an implementation manifest. It should be converted into a precise URL-level CSV before any deletion, redirect or sitemap change.

| Disposition | Recommended count | Meaning |
|---|---:|---|
| KEEP | 115 | Strong calculator, trust, authority, hub and decision pages that already fit V2. |
| REPURPOSE | 45 | Existing URLs that can become stronger V2 calculator/hub resources without changing their broad intent. |
| CONSOLIDATE | 50 | Overlapping guides/comparison pages that should be merged into stronger resources. |
| REDIRECT | 240 | URLs with a clear one-to-one or close replacement. Use sparingly. |
| REMOVE | 24,592 | Salary ladder URLs and variants with no distinct V2 purpose or safe semantic replacement. |

Total modelled canonical URLs: 25,042

## Redirect Rules

Do not blanket-redirect salary ladders to the homepage. Redirect only when the replacement substantially satisfies the same user intent. Most old salary-number URLs should leave the canonical inventory and eventually return 404/410 rather than be forced into unrelated calculators.

## Historical Value Caution

Some broad URLs may have historical value even if their current content is not ideal. Keep or repurpose broad hubs and high-level calculators first; do not casually delete pages that still appear in GSC or have external links until sampled.
